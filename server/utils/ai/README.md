# AI 目录说明（后端）

本目录用于存放与 AI 能力相关的“可维护资产”，目标是让能力边界、知识来源与引用规范一眼可查，便于长期演进。

## 目录结构

- `skills/`
  - 面向模型的技能手册（Markdown），用于约束工具优先级、参数范式、解释框架与输出格式。
- `core/`
  - AI 核心运行模块（客户端/中间件/工具清单/路由器等）。
- `corpus/`
  - 可维护的内置知识条目（JSON），用于“可引用的权威出处”与“结构化背景”检索。
  - 目前包含政策/规划索引：`policy_corpus.json`
- `checkOllama.js`
  - 本地 Ollama 服务可用性检查（启动时运行）。

## 重要约束

- 所有中文文本与 JSON 文件必须使用 UTF-8 编码。
- 政策/规划引用必须先通过工具检索命中条目，再在正文输出 `来源:` 链接。
