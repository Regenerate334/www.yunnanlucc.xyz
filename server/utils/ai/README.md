# AI 目录说明（后端）

本目录用于存放与 AI 能力相关的“运行代码”。

说明：AI 的“知识资源”（skills/图谱/语料/本体/目录索引等）已统一归档到 `server/knowledge/`，避免与运行代码混放导致路径混乱与维护困难。

## 目录结构

- `core/`
  - AI 核心运行模块（客户端/中间件/工具清单/路由器等）。
- `checkOllama.js`
  - 本地 Ollama 服务可用性检查（启动时运行）。

## 重要约束

- 所有中文文本与 JSON 文件必须使用 UTF-8 编码。
- 政策/规划引用必须先通过工具检索命中条目，再在正文输出 `来源:` 链接（对应资源位于 `server/knowledge/`）。
