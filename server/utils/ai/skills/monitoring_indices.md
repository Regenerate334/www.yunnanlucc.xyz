# 生态环境风险监测与评估（核验重构版）

本技能用于解释右侧面板监测指标，口径必须与后端 `landUseService.getRegionMonitoring` 保持一致。

> 重要边界：HQ/CMP/ERes/PLEC 为 **面积统计代理指标（proxy）**，用于监测与相对比较；不等同于 InVEST 等过程模型的“真值输出”，也不依赖能源清单。

## 1. 指标定义（与后端一致）

### 1.1 生境支持指数（HQ）
- 公式：`HQ = Σ(Area_i × w_i) / TotalArea × 100`
- 权重映射（CLCD）：
  - 林地/灌木：0.35
  - 草地：0.21
  - 水域/湿地：0.28
  - 耕地：0.11
  - 建设用地：0.04
  - 裸地/冰雪：0.01
- 解释：值越高通常代表生态支撑更好（风险方向与 CMP/PLEC 相反）。

### 1.2 土地利用碳压指数（CMP）
- 公式：`CMP = (碳源/碳汇) × (1 + 建设用地占比)`
- 系数：
  - 碳源：`耕地 × 0.422`
  - 碳汇：`(林地+灌木)×0.612 + 草地×0.021 + (水域+湿地)×0.235 + (裸地+冰雪)×0.005`
- 解释：值越高碳压越大，风险越高。

### 1.3 生态韧性指数（ERes）
- 公式：`ERes = Σ(Area_i × r_i) / TotalArea × 100`
- 系数：
  - 林地：0.9，灌木：0.8，草地：0.7
  - 水域/湿地：0.8，耕地：0.5
  - 建设用地：0.2，裸地/冰雪：0.1
- 解释：值越高韧性越强（风险方向与 CMP/PLEC 相反）。

### 1.4 三生空间压力比（PLEC）
- 公式：`PLEC = (2×生活空间 + 生产空间) / 生态空间`
- 映射：
  - 生活空间：建设用地
  - 生产空间：耕地
  - 生态空间：林地+灌木+草地+水域+湿地
- 解释：值越高说明生活/生产对生态空间挤压越强。

## 2. 风险评分与综合

### 2.1 单指标风险分（0-100）
- 基于 `1985~当前年` 历史序列做 Min-Max 标准化。
- 风险正向指标：CMP、PLEC（值越大风险越大）。
- 风险反向指标：HQ、ERes（值越大风险越小，需反向映射）。

### 2.2 综合指数
- 方法：熵权法（Entropy Weight）。
- 输出：
  - `weights`：四指标动态权重
  - `compositeScore`：加权综合风险分

## 3. 回答规范（给 AI）

1. 解释指标时，必须说明“该系统采用面积统计代理模型”，不要宣称“完整 InVEST”。  
2. 若用户追问权重来源，先报 `weights` 字段（熵权法动态结果），再解释其含义。  
3. 不得引用已废弃的“固定权重 + 极值惩罚 40%”口径。  
4. 不得把 `STOTEN 858:159828` 用作生态韧性依据。  
5. 若用户只关心“LUCC 变化监测”，优先建议使用：面积与占比、单一/综合动态度、转移矩阵（净变化/交换变化）等指标框架（参见文档 `docs/algorithms/LUCC_Algorithms_2021_2026.md` 的 2.4 节）。
