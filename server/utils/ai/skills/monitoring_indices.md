# 生态环境风险监测与评估 (2021-2026 范式)

本技能定义了云南省土地利用动态监测中的四个核心生态指标的计算逻辑、阈值判定及分析要点。

## 1. 指标体系定义

### 1.1 InVEST 生境质量 (HQI)
- **定义**: 评估区域生物多样性保障能力及生境退化程度。
- **权重**: 
  - 林地/湿地: 1.0 (核心生境)
  - 水体: 0.9
  - 灌木: 0.8
  - 草地: 0.7
  - 耕地: 0.3 (低质量生境)
  - 裸地/冰雪: 0.1
  - 建设用地: 0 (生境丧失)
- **分析要点**: 
  - 长期下降通常意味着毁林开荒或过度城市化。
  - 分值范围 [0, 100]，分值越高生境越优。

### 1.2 源汇碳代谢压力 (CMPI)
- **定义**: 区域碳排放（源）与碳吸收（汇）的平衡状态。
- **计算逻辑**: `(建设用地 * 50 + 耕地 * 0.42) / (林地 * 0.58 + 灌木 * 0.20 + 水/湿地 * 0.25 + 草地 * 0.02)`
- **风险判定**:
  - < 0.5: 安全 (汇 > 源)
  - 0.5 - 1.0: 代谢承压
  - > 1.0: 严重风险 (碳源过载)

### 1.3 全域生态韧性度 (ERes)
- **定义**: 地表系统在受到外界干扰后的自我修复与调节能力。
- **分析要点**: 衡量区域作为“生态海绵”的有效性。高得分区域应优先保护。

### 1.4 三生空间冲突度 (PLEC)
- **定义**: 生产空间（耕地）、生活空间（建设用地）与生态空间（林草水湿）的博弈剧烈程度。
- **计算公式**: `(生活 * 2 + 生产 * 1) / 生态`
- **注意**: 生态空间不包括“裸地”与“冰雪”，以避免极端地貌对评估结果的稀释。
- **判定**: 冲突度越高，代表城镇化或耕地扩张对生态空间的侵蚀越严重。

## 2. 预警阈值与结论推导
- **综合风险得分 (Composite Score)**:
  - 0 - 25: 🟢 安全/协同
  - 25 - 50: 🟡 关注/边缘
  - 50 - 75: 🟠 警告/博弈 (建议加强规划管制)
  - 75 - 100: 🔴 严重/侵蚀 (必须启动生态修复)

## 3. 当遇到矛盾时
- 如果 `clcd_analysis` 的原始面积数据与监测得分看似矛盾（例如林地增加但得分下降），应检查是否是由于“建设用地”扩张速度远超林地补偿速度导致的“源汇失衡”。
