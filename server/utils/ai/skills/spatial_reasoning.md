# 空间推理与空间统计（Skill 2.0 操作手册）

本技能用于指导你在本系统中完成“空间重心迁移轨迹、标准差椭圆（SDE）、偏移方位角/距离、扩张形态诊断”等任务时，**如何优先调用工具拿到可信结果**，并把结果解释给用户。

## 1. 适用问题范围（触发关键词）

当用户问题包含以下任一类诉求时，必须使用本技能指导的工具路由：

- “重心 / 迁移 / 偏移 / 轨迹 / 演变路径”
- “方位角 / 角度 / 朝向 / 向哪个方向移动”
- “偏移距离 / 移动了多少 km”
- “标准差椭圆 / 椭圆面积 / 主轴方向 / 扁率 / 方向性”
- “单极核聚集 / 多点扩散 / 多中心蔓延 / 轴向扩张”
- “净流入 / 净流出 / 净转入 / 净转出（建设用地净流入、耕地净流出等）”

## 2. 工具优先原则（核心约束）

1. **任何涉及精确数值与空间统计指标的问题，都必须先调用业务工具检索/计算**，再组织最终结论。
2. **严禁**拿 `clcd_analysis` 的基础面积趋势表让模型自行推导：重心迁移、SDE、方位角、距离、椭圆面积、扁率等复杂空间统计。
3. 若用户要求 TopN（例如“最大 5 个县”“头部集中度”），优先让工具直接返回 TopN 与集中度，**严禁模型手算汇总**。
4. 同一 session 内也不得“凭上一轮记忆”复用精确数值结论：每个数值型问句都至少要调用一次相关工具做核验。

## 3. 意图 → 工具路由表（最重要）

| 用户意图 | 必选工具 | 说明 |
| --- | --- | --- |
| 某类“转化活动”的空间重心迁移轨迹、偏移方向/距离 | `spatial_stats_analysis` | 工具会返回多期重心与轨迹线，并提供 bearing/distance 等可引用指标 |
| 标准差椭圆（SDE）主轴方向、面积变化、扁率变化 | `spatial_stats_analysis` | 工具返回每期 SDE 几何与关键参数（角度/面积/扁率） |
| “单极核聚集 vs 多点散发”扩张形态诊断 | `spatial_stats_analysis` +（必要时）`knowledge_base_lookup(skill_name="spatial_reasoning")` | 先拿 SDE 面积/扁率/重心轨迹等证据，再给定性诊断 |
| 只问“某县/某州在某时段哪类地类转化最强、TopN 区域” | `spatial_stats_analysis` 或 `land_transfer_analysis` | 需要空间定位/迁移轨迹用 spatial_stats；只要矩阵强度用 transfer |
| 需要解释“指标为什么这样”“业务口径是什么”“政策影响链路” | `knowledge_base_lookup(skill_name="policy_expert")` | 先用工具找到异常，再用政策技能解释因果 |

## 4. 参数填写范式（强约束）

### 4.1 `spatial_stats_analysis`（核心）

调用参数（必须提供）：

- `yearStart`: 起始年份（整数）
- `yearEnd`: 结束年份（整数，必须 > yearStart）
- `fromClassStr`: 转出地类中文名，例如：`"林地"`, `"耕地"`
- `toClassStr`: 转入地类中文名，例如：`"建设用地"`

可选参数：

- `region`: 目标区域名称，例如：`"昆明市"`、`"云南省"`（不传默认全省）
- `top_n`: TopN 数量（默认 5；当用户问“最大5县”必须显式传 5）

常见映射示例：

- 建设用地扩张（林地转建设）：`fromClassStr="林地"`, `toClassStr="建设用地"`
- 林地转耕地：`fromClassStr="林地"`, `toClassStr="耕地"`
- 建设用地净流入（全部转入建设用地）：`fromClassStr="全部"`, `toClassStr="建设用地"`
- 耕地净流出（耕地转出到全部）：`fromClassStr="耕地"`, `toClassStr="全部"`

> 注意：本项目的 transfer 宽表为 8 类口径（灌木并入林地），并采用重编码：  
> `1耕地 2林地(含灌木) 3草地 4水体 5冰雪 6裸地 7建设用地 8湿地`。  
> 因此当你调用 `spatial_stats_analysis` / `land_transfer_analysis` 时，“建设用地”对应的是 **7**（不是 5）。

### 4.2 `land_transfer_analysis`（补充）

当用户只需要“转移矩阵强度与净变化/交换变化”而不需要空间几何时，用：

- `region`: 区域
- `start_year`, `end_year` 或 `period`
- `level`: `province/prefecture/county`

## 5. 输出解读模板（只讲怎么解释，不做自算）

当工具返回 bearing/distance/SDE 指标时，回答必须包含以下结构：

1. **核心结论（开篇一句话）**：重心整体向哪个象限（东北/西南等）偏移、偏移距离大致多少、主轴方向是否稳定。
2. **证据链（必须可回指工具结果）**：
   - 重心：起点坐标/终点坐标、bearing（方位角）、distance_km（偏移距离）
   - SDE：每期椭圆面积变化（扩大/缩小）、扁率变化（方向性增强/减弱）、主轴角度变化（是否转向）
3. **扩张形态诊断**：
   - 面积缩小 + 扁率增大（方向性更强）常对应“单极核聚集 + 轴向拉伸”
   - 面积扩大 + 扁率趋近 1 常对应“多点扩散式蔓延”
4. **不确定性声明**（当工具返回缺失项时）：
   - “当前 period 切片不足/无 SDE（点数不足）/轨迹为空”，需提示用户调整时段或地类方向。

## 6. 失败兜底（必须按以下顺序处理）

1. **401/鉴权失败**：本项目的 `spatial_stats_analysis` 已在工具侧直接计算轨迹与 SDE，不应再依赖内部 HTTP 回调；如仍出现 401，请检查是否有其它工具在请求受鉴权保护的 `/api/analysis` 路由。
2. **无数据**：说明指定时段/地类方向/区域无转化记录或字段不存在，建议：
   - 放宽区域（从县→州→省）
   - 放宽时段（扩大 yearStart-yearEnd）
   - 更换地类方向（例如 耕地→建设 与 林地→建设）
3. **region 模糊**：要求用户明确到“省/州/县（区）”层级后再分析（系统不提供地图视角控制能力）。
