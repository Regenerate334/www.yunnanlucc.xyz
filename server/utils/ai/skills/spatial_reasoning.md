# 土地分析空间推理 (Spatial Reasoning)

本技能定义了如何解读 WebGIS 系统输出的空间统计特征，包括重心迁移轨迹（Centroid Tracking）和标准差椭圆（SDE）。

## 1. 重心迁移轨迹 (Centroid Tracking)
- **物理意义**: 代表某种地类（或地类转化活动）在地理空间上的“质量中心”随时间的变化。
- **分析逻辑**: 
  - **偏移方向**: 如果耕地向建设用地的转化重心向“北”移动，说明该区域北部的城镇开发强度正在超越南部。
  - **偏移距离**: 偏移距离越远，说明开发活动的地理极化现象越明显。
  - **路径复杂度**: 直线移动代表开发计划的一致性；曲折移动可能代表政策导向的阶段性调整。

## 2. 标准差椭圆 (SDE)
- **主轴方向 (Orientatn)**: 代表现象扩张的主要方向带。例如，长轴呈东北-西南走向，代表该地类主要沿此轴线轴向分布。
- **椭圆面积**: 面积缩小代表现象集聚（空间极化）；面积扩大代表现象扩散（全域散布）。
- **扁率 (Ratio)**: 扁率越大，空间方向性越强；扁率趋近于1（圆形），代表空间无序或均匀扩张。

## 3. 结果解读模板
> “根据当前轨迹分析，[地类A] 转 [地类B] 的空间活动重心在 [年份范围] 内从 [A点] 持续移向 [B点]，整体呈现出向 [XX方向] 演进的显著趋势。对应的标准差椭圆主轴显示，该活动在空间上深受 [XX地理要素/政策带] 的影响，具有极强的轴向拉伸特征。”

## 5. 语义联动 (Knowledge Graph Linkage)
- **强制原则**: 严禁在未检索图谱的情况下拒绝关于“政策”、“地名别名”或“业务逻辑”的问题。
- **思考链路**: 
  1. `意图识别` -> 识别到“政策”、“指标定义”或“区域属性”关键词。
  2. `调用知识查询` -> 使用 `knowledge_query` 工具。
  3. `语义合流` -> 将图谱返回的政策背景、权重系数注入到最终的数据分析结论中。
- **目标**: 实现“数据统计”与“知识推演”的深度耦合。
