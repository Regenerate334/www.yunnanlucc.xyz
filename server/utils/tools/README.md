# tools 目录说明（后端）

本目录用于存放“可被大模型调用”的工具实现（FunctionTool / Registry 工具）。为了便于维护，真实实现按职责拆分到子目录；根目录下的文件目前仍保留为兼容转发层（便于现有入口文件不大改），但建议在新代码中优先直接引用子目录实现。

## 目录结构

- `analysis/`
  - 业务分析类工具：CLCD、仪表盘、空间统计、流转矩阵、天气等。
- `knowledge/`
  - 知识与引用类工具：知识库、知识图谱、政策/规划索引检索等。

## 兼容层说明（现状 + 建议）

本次变更采用“全量更新引用路径”的策略：

- 不再保留根目录的同名转发文件
- 所有入口与 import 统一显式引用 `analysis/` 与 `knowledge/` 下的实现

## 编码约束

所有中文文本与 JSON 文件必须使用 UTF-8 编码（遵循仓库 `AGENTS.md`）。
