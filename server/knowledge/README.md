# knowledge 目录说明（后端知识资源）

本目录用于存放“AI 可引用/可检索”的知识资源（不含运行代码）。目标是把 **技能手册、知识图谱、政策索引、本体与目录索引** 等统一归档，做到路径清晰、可维护、可扩展。

## 目录结构

- `skills/`
  - 面向模型的技能手册（Markdown）。用于解释框架、工具调用规范、引用规则等。
- `corpus/`
  - 可维护的知识条目/索引库（JSON）。例如政策与规划文献索引库。
- `graph/`
  - 知识图谱数据（JSON），用于语义节点与关系查询（由 `knowledge_graph_query` 工具读取）。
- `ontology/`
  - 本体与口径定义（JSON），用于描述实体类别、指标权重与关系谓词等。
- `catalog/`
  - 数据目录/表摘要（JSON），用于描述数据库可用表、年份范围、跨期列表等（如需要可以接入为工具）。

## 关键原则

- 所有中文文本与 JSON 必须使用 UTF-8 编码（遵循仓库 `AGENTS.md`）。
- 模型在回答中引用政策/规划等权威出处时，必须先通过工具检索命中条目，再在正文中输出 `来源:` 链接。
