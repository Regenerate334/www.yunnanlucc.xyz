API 参考文档

基础地址: http://localhost:3000
除 /api/auth/*、/api/weather 和 /health 外，所有接口均需要 JWT 令牌认证。 请在请求头中添加: Authorization: Bearer {token}

用户认证

POST /api/auth/login 无需认证

用户登录接口。验证用户名和密码，成功后返回 JWT 令牌。令牌有效期为 24 小时。

请求参数
参数名 类型 必填 说明
username string 必填 用户名
password string 必填 密码
返回值
Object - 包含令牌和用户信息的对象
响应示例
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "admin",
    "role": "admin"
  }
}
POST /api/auth/register 无需认证

用户注册接口。创建新用户账号，密码使用 bcrypt 加密存储。

请求参数
参数名 类型 必填 说明
username string 必填 用户名，至少 3 个字符，不能与已有用户重复
password string 必填 密码，至少 6 个字符
返回值
Object - 包含注册结果和用户信息
GET /api/auth/verify 需要认证

验证令牌有效性。如果令牌有效，返回解码后的用户信息；如果令牌无效或已过期，返回 401 错误。

返回值
Object - 包含用户 ID、用户名和角色

土地利用数据

GET /api/clcd/years 需要认证

获取数据集中可用的年份列表。数据来源于中国土地覆盖数据集 (CLCD)，时间跨度为 1985-2023 年。

返回值
Array<number> - 年份数组
响应示例
[1985, 1990, 1995, 2000, 2005, 2010, 2015, 2020, 2023]
GET /api/clcd/{year}/summary 需要认证

获取指定年份云南省各土地利用类型的面积汇总数据。

路径参数
参数名 类型 说明
year number 目标年份，如 2023、2020 等
返回值
Array<Object> - 各地类面积汇总数组
响应示例
[
  { "class_code": 1, "class_name": "Cropland", "area_km2": 57432.15 },
  { "class_code": 2, "class_name": "Forest", "area_km2": 198234.88 },
  { "class_code": 3, "class_name": "Shrub", "area_km2": 12345.67 }
]
GET /api/clcd/province 需要认证

获取云南省省级土地利用时间序列数据。返回宽表格式，每行包含一个年份的所有地类面积。面积单位为平方米 (m²)。

返回值
Array<Object> - 各年份数据数组
GET /api/clcd/prefecture 需要认证

获取云南省 16 个地级市（州）的全量土地利用数据。包含所有年份和所有地类的面积信息。

GET /api/clcd/county 需要认证

获取云南省所有区县的全量土地利用数据。包含所有年份和所有地类的面积信息。

GET /api/clcd/trend/{level}/{name} 需要认证

获取指定区域的土地利用历史变化趋势数据。可查询地级市或区县级别的多年数据。

路径参数
参数名 类型 说明
level string 行政级别: prefecture (地级市) 或 county (区县)
name string 区域名称，如"昆明市"、"五华区"（需进行 URL 编码）
请求示例
GET /api/clcd/trend/prefecture/昆明市
GET /api/clcd/trend/county/官渡区

行政区划

GET /api/regions/{level} 需要认证

获取云南省行政区划列表或层级结构。支持获取省-市-县三级结构、地级市列表或区县列表。

路径参数
参数名 类型 说明
level string hierarchy - 返回省-市-县树形结构
prefecture - 返回地级市名称数组
county - 返回区县名称数组
hierarchy 响应示例
[
  { "name": "昆明市", "children": ["五华区", "盘龙区", "官渡区", "西山区", ...] },
  { "name": "曲靖市", "children": ["麒麟区", "沾益区", "马龙区", ...] }
]

空间分析

GET /api/analysis/transfer-matrix/periods 需要认证

获取土地利用转移矩阵可用的时间周期列表。转移矩阵用于分析不同时期之间各地类的面积转换情况。

返回值
Array<string> - 时间周期字符串数组
响应示例
["1990-2000", "2000-2010", "2010-2020", "2020-2023"]
GET /api/analysis/transfer-matrix/{period} 需要认证

获取指定时间段的土地利用转移矩阵。返回绝对量矩阵（面积值）和百分比矩阵（转移比例）。

路径参数
参数名 类型 说明
period string 时间周期，格式为"起始年-结束年"，如 2010-2020
返回值
Object - 转移矩阵对象
响应示例
{
  "absoluteMatrix": [[0, 1234.5, 567.8, ...], ...],
  "percentageMatrix": [[0, 0.025, 0.011, ...], ...],
  "landTypes": ["Cropland", "Forest", "Shrub", "Grassland", "Water", "Barren", "Impervious", "Wetland"],
  "period": "2010-2020"
}
GET /api/analysis/dashboard/{year} 需要认证

获取大屏看板综合数据。包含省份土地利用汇总、土地利用动态度排行榜、预警信息等。

路径参数
参数名 类型 说明
year number 目标年份，如 2023
查询参数
参数名 类型 必填 说明
type string 可选 动态度计算类型，默认 comprehensive（综合动态度）
可选值: comprehensive | cropland | forest | grassland | impervious | water
返回值
Object - 包含 summary、ranking、alerts 等字段

气象服务

GET /api/weather 无需认证

获取实时天气或天气预报数据。该接口代理高德天气 API，自动添加天气图标。

查询参数
参数名 类型 默认值 说明
city string 530100 城市行政区划代码，如昆明市为 530100
extensions string base base - 实况天气 | all - 天气预报
请求示例
GET /api/weather?city=530100&extensions=base

智能分析

POST /api/ai/analyze-stream 需要认证

AI 驱动的土地利用数据智能分析接口。支持自然语言提问，系统会自动注入相关数据上下文，返回 SSE (Server-Sent Events) 流式响应。

请求参数
参数名 类型 必填 说明
messages Array<Object> 必填 对话消息数组，每条消息包含 role ("user" 或 "assistant") 和 content 字段
year number 可选 分析的目标年份，默认 2023
componentContext Object 可选 组件上下文对象，type 可选: province_trend | prefecture_pie | county_pie
model string 可选 AI 模型名称，默认 gpt-oss:20b。可选模型见AI模型列表
返回值
text/event-stream - SSE 流式响应
请求示例
{
  "messages": [
    { "role": "user", "content": "分析云南省近40年耕地面积变化趋势" }
  ],
  "year": 2023,
  "componentContext": { "type": "province_trend" },
  "model": "gpt-oss:20b"
}
响应格式
data: {"content": "根据"}
data: {"content": "数据分析"}
data: {"content": "，云南省耕地..."}
data: {"done": true}
GET /api/ai/suggestions 需要认证

获取 AI 分析建议问题列表。返回一组预设的分析问题，可用于引导用户进行数据分析。

响应示例
{
  "success": true,
  "suggestions": [
    "分析云南省近40年的耕地变化趋势",
    "对比昆明和曲靖的建设用地占比",
    "查看2023年各地级市的林地排名",
    "分析滇中地区的土地利用结构特点"
  ]
}

会话管理

GET /api/chat-sessions 需要认证

获取当前用户的所有对话会话列表。按更新时间倒序排列。

返回值
Object - 包含 sessions 数组，每个会话有 id、title、created_at、updated_at 字段
POST /api/chat-sessions 需要认证

创建新的对话会话。

请求参数
参数名 类型 必填 说明
title string 可选 会话标题，默认为"新对话"
DELETE /api/chat-sessions/{id} 需要认证

删除指定的对话会话。只能删除当前用户创建的会话。

路径参数
参数名 类型 说明
id number 会话 ID
GET /api/chat-sessions/{id}/messages 需要认证

获取指定会话的所有消息记录。只能获取当前用户创建的会话消息。

返回值
Object - 包含 messages 数组，每条消息有 role、content、created_at 字段
POST /api/chat-sessions/{id}/messages 需要认证

向指定会话添加新消息。如果是用户的第一条消息且会话标题为"新对话"，系统会异步调用 AI 自动生成智能标题。

请求参数
参数名 类型 必填 说明
role string 必填 消息角色: user (用户) 或 assistant (AI助手)
content string 必填 消息内容

类型定义

土地利用类型 (LandUseType)

CLCD 土地利用分类体系，共 9 种地类。

代码 英文名称 中文名称 说明
1 Cropland 耕地 农业生产用地，包括水田和旱地
2 Forest 林地 森林资源覆盖区域
3 Shrub 灌木 灌木丛覆盖区域
4 Grassland 草地 天然草地和人工草地
5 Water 水体 湖泊、河流、水库等
6 Snow/Ice 冰雪 永久性冰雪覆盖区域
7 Barren 裸地 无植被覆盖的地表
8 Impervious 建设用地 城市建成区、道路等不透水面
9 Wetland 湿地 湿地生态系统
AI 模型列表 (AIModel)

系统支持的本地 AI 推理模型，基于 Ollama 运行。

模型标识 参数量 特点
gpt-oss:20b 20B 默认模型，分析能力与响应速度平衡
deepseek-r1:8b 8B 标准模式，适合一般分析任务
gemma3:4b 4B 快速模式，响应迅速
deepseek-r1:1.5b 1.5B 极速模式，适合简单问答
